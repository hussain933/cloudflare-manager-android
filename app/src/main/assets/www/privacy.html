Privacy Policy

Last updated: July 2026

1. No Data Collection

Cloudflare Manager does not collect, transmit, or store any personal data on external servers. All app data (settings, logs, the cloudflared binary) stays on your device in the app's private storage.

2. Network Access

The app makes the following network requests:

  • cloudflared tunnel traffic — when you start a tunnel, cloudflared connects to Cloudflare's edge servers to establish the tunnel. This is the core function of the app.
  • GitHub Releases API — the app periodically checks for newer versions of the cloudflared binary at api.github.com/repos/cloudflare/cloudflared/releases/latest. No personal data is sent in this request.

3. Local Permissions

The app requires certain Android permissions (INTERNET, FOREGROUND_SERVICE, WAKE_LOCK, POST_NOTIFICATIONS) solely to provide its core functionality. None of these are used to collect data about you.

4. Logs

The app writes cloudflared output logs to your device's private storage. These logs are not uploaded anywhere. You can view them via the Settings → View Logs option, or delete them by clearing the app's storage.

5. Contact

If you have questions about this privacy policy, you may contact the developer through the app's distribution channel.
